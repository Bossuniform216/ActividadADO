Actividad ADO.NET y SQLite
Descripción
Proyecto de consola desarrollado en C# utilizando ADO.NET y SQLite.

Requisitos cumplidos
Creación de base de datos SQLite.
Uso de SqliteConnection.
Uso de SqliteCommand.
Creación de tabla.
Inserción de registros.
Consulta mediante SqliteDataReader.
Uso de using para liberar recursos.
Ejecución
dotnet restore
dotnet run
Evidencias
Las capturas se encuentran dentro de la carpeta evidencias.
